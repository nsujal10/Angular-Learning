Day 4 Architectural Upgrades

  • ✓
    Real Backend Integration:

    Node.js HTTP REST server listening on port 3000 mapped via proxy.conf.json.

  • ✓
    HTTP Interceptor with Token Rotation:

    Attaches Bearer tokens, intercepts 401s, silently requests /api/auth/refresh, and transparently retries requests.

  • ✓
    Authorization Enforcement:

    Backend rejects deletions from non-admins with HTTP 403; Angular routes them to /forbidden.

  • ✓
    UX Resilience:

    Loading states, empty states, error recovery, and confirmation modals.
